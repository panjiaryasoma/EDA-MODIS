# EDA MODIS Indonesia (2000)

Tugas Mandiri Pertemuan 6: **Data Cleaning dan Exploratory Data Analysis (EDA)**, mata kuliah Data Mining.

## Isi repository
- `EDA_MODIS_P6_Final.ipynb`: notebook yang sudah dieksekusi, berisi persiapan data, pembersihan, lima pertanyaan analisis, visualisasi, dan kesimpulan.
- `modis_2000_Indonesia.csv`: dataset sumber (691 rekaman, 15 kolom).
- `Ringkasan_EDA_MODIS_P6_Final.pdf`: laporan ringkasan dua halaman.

## Cara menjalankan
1. Buka `EDA_MODIS_P6_Final.ipynb` di Google Colab atau Jupyter.
2. Unggah `modis_2000_Indonesia.csv` ke direktori kerja notebook jika belum tersedia.
3. Jalankan cell dari atas ke bawah.

## Cakupan dan keterbatasan
Data berisi rekaman deteksi anomali panas MODIS di Indonesia pada 1 November–31 Desember 2000. **Jumlah deteksi hotspot bukan jumlah kejadian kebakaran terverifikasi.** Kategori sumber panas dan cakupan sensor perlu dipertimbangkan saat menafsirkan temuan.

Analisis ini disiapkan untuk tugas akademik, bukan untuk sistem peringatan dini kebakaran operasional.
